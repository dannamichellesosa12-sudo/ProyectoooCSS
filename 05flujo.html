Flujo normal y Display

Introducción

El flujo normal coloca los elementos uno debajo de otro. Con display podemos cambiar su comportamiento.

Ejemplos

Bloque

Un elemento de bloque ocupa todo el ancho disponible y se coloca en una nueva línea.

Texto antes Inline texto después

Un elemento en línea solo ocupa el espacio de su contenido y se coloca junto a otros.

Texto antes Inline-block texto después

Un elemento inline-block se comporta como en línea, pero permite definir ancho y alto.

Flex item 1
Flex item 2

Los elementos dentro de un contenedor flex se alinean y distribuyen según las reglas de flexbox.
